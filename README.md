# Atlas Trading Command Center

Project: Market Analysis Dashboard

AI Supervisor: Honey

Purpose:
Build and validate two independent automated trading strategies.

Strategy A:
Patient High-Confidence. Only trade when strict, validated qualification rules are met. Otherwise, NO TRADE.

Strategy B:
Aggressive Short-Term. Seek short-term opportunities using separate entry, exit, and risk rules.

Development Rules:
1. Begin with simulated accounts.
2. Record every signal, trade, cost, and outcome.
3. Enforce risk limits in software.
4. Never assume a probability is proven without validation.
5. Require approval before changing strategy rules.
6. Do not enable live trading until testing requirements are met.

Initial Test Budget:
$100 per strategy, reserved for a future approved live test.

Current Phase:
Phase 1 - Foundation and Simulation.
